# 🌍 Worldwide Country Random Name Generator Telegram Bot

বিশ্বের যেকোনো দেশের কালচারাল ও অথেন্টিক নাম আনলিমিটেড জেনারেট করার জন্য একটি সম্পূর্ণ পাইথন টেলিগ্রাম বট।

---

## 🌟 প্রধান ফিচারসমূহ (Features):
1. **বিশ্বের ১৯৬ টি দেশ (Worldwide 196+ Countries):**
   - প্রতিটা দেশের নিজস্ব পতাকা (Flag emoji) ও সঠিক ISO কোড।
2. **প্রথম পেজে ৬টি টপ কান্ট্রি ও সহজ নেভিগেশন:**
   - প্রথম পেজে সরাসরি ৬টি জনপ্রিয় দেশ (যেমন: Bangladesh 🇧🇩, USA 🇺🇸, UK 🇬🇧, India 🇮🇳, Japan 🇯🇵, Germany 🇩🇪) থাকবে।
   - পরবর্তী পেজ দেখার জন্য **⬅️ Prev** এবং **Next ➡️** পেজিনেশন বাটন।
3. **স্মার্ট সার্চ অপশন (Search by Country Name or Code):**
   - যেকোনো সময় **🔍 Search Country** বাটনে ক্লিক করে বা সরাসরি মেসেজে দেশের নাম লিখে সার্চ করা যায় (যেমন: `bd`, `bangladesh`, `usa`, `japan`, `germany`, `russia` ইত্যাদি)।
4. **আনলিমিটেড নাম জেনারেটর (Unlimited Generation):**
   - দেশ সিলেক্ট করলেই সাথে সাথে সেই দেশের কালচার অনুযায়ী মানুষের ফার্স্ট নেম ও লাস্ট নেম তৈরি হবে।
   - **🔄 Generate Again (5 Names)** এবং **⚡ Generate 10** বাটনে ক্লিক করে যত ইচ্ছা আনলিমিটেড নাম পাওয়া যাবে।
5. **জেন্ডার ফিল্টার (Gender Filters):**
   - 👥 **Both** (উভয় জেন্ডারের নাম)
   - 👨 **Male** (শুধু পুরুষদের নাম)
   - 👩 **Female** (শুধু মহিলাদের নাম)
6. **জিরো ডিপেন্ডেন্সি (Zero External Dependencies):**
   - কোনো থার্ড পার্টি লাইব্রেরি ইনস্টল করার ঝামেলা নেই। স্ট্যান্ডার্ড পাইথন ৩ লাইব্রেরি দিয়েই তৈরি।

---

## 📁 ফাইল স্ট্রাকচার:
- `bot.py`: প্রধান বট স্ক্রিপ্ট এবং টেলিগ্রাম ইন্টারঅ্যাকশন লজিক।
- `countries_data.py`: বিশ্বের ১৯৬টি দেশের তালিকা, ফ্ল্যাগ এবং সার্চ ইঞ্জিন।
- `name_generator.py`: ৫৭টি কালচারাল নেম-পুল থেকে ফার্স্ট ও লাস্ট নেম জেনারেটর।
- `telegram_client.py`: লাইটওয়েট ও ফাস্ট টেলিগ্রাম বট API ক্লায়েন্ট।
- `.env.example`: টোকেন কনফিগারেশন ফাইল।

## 🚀 কীভাবে চালাবেন (How to Run):

### ধাপ ১: Telegram Bot Token সংগ্রহ করুন
1. টেলিগ্রামে গিয়ে সার্চ করুন **@BotFather**
2. `/newbot` লিখে পাঠান এবং নির্দেশনা অনুযায়ী বটের একটি নাম ও ইউজারনেম দিন।
3. BotFather আপনাকে একটি **API Token** দেবে (যেমন: `7123456789:ABCdefGhIJKlmNoPQRstuVWxYz`).

### ধাপ ২: বট চালু করুন
টার্মিনাল ওপেন করে প্রজেক্ট ফোল্ডারে যান এবং নিচের যেকোনো একটি উপায়ে রান করুন:

#### উপায় ১ (সরাসরি আর্গুমেন্ট দিয়ে):
```bash
cd /Users/jony/.gemini/antigravity/scratch/world-name-generator-bot
python3 bot.py YOUR_BOT_TOKEN
```
*(এখানে `YOUR_BOT_TOKEN` এর জায়গায় আপনার টেলিগ্রাম বট টোকেনটি বসিয়ে দিন)*

#### উপায় ২ (Environment Variable দিয়ে):
```bash
export TELEGRAM_BOT_TOKEN="YOUR_BOT_TOKEN"
python3 bot.py
```

#### উপায় ৩ (ইন্টারেক্টিভ প্রম্পট):
সরাসরি চালান, স্ক্রিপ্ট নিজে থেকেই আপনার কাছে টোকেন চেয়ে নিবে:
```bash
python3 bot.py
```

## 📱 টেলিগ্রামে যেভাবে ব্যবহার করবেন:
1. বটের চ্যাটে গিয়ে `/start` চাপুন।
2. প্রথম পেজে ৬টি দেশ এবং নিচে পেজ পরিবর্তনের বাটন দেখতে পাবেন।
3. যেকোনো দেশের নামের ওপর ক্লিক করলে সাথে সাথে সেই দেশের নাম জেনারেট হয়ে যাবে।
4. **🔄 Generate Again** বাটনে চাপ দিলে প্রতি ক্লিকেই আনলিমিটেড নতুন নাম আসবে।
5. অন্য দেশ চাইলে **🔍 Search Country** তে চাপ দিয়ে দেশের নাম লিখে পাঠান!
